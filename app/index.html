一、引言

欢迎使用 [亿讯企业版] app！本隐私协议由衡阳允阳科技有限公司（以下简称“我们”）制定，旨在向你说明我们如何收集、使用、存储和共享你的个人信息，以及你对个人信息享有的权利。请你仔细阅读本隐私协议，在你使用我们的服务前，你被视为已经理解并同意本协议的全部内容。

二、我们收集的信息

  1. 注册与账户信息
    • 当你注册账户时，我们可能会收集你的手机号码、电子邮箱地址、用户名、密码等信息，用于创建和管理你的账户。
    • 你也可以选择提供头像、昵称、个性签名等个人资料信息，以完善你的账户资料。
  2. 通讯信息
    • 当你使用即时通讯功能时，我们会收集你发送和接收的消息内容、图片、视频、文件等信息，以及消息的发送时间、接收时间、联系人信息等。
    • 为了实现语音通话、视频通话功能，我们会收集你的语音、视频数据。
  3. 设备信息
    • 我们会收集你的设备型号、操作系统版本、设备唯一标识符、网络设备硬件地址（MAC 地址）等信息，用于保障服务的稳定性和安全性，以及进行设备识别和管理。
  4. 位置信息
    • 如果你开启了位置共享功能，我们会收集你的实时位置信息，用于实现位置共享、附近的人等功能。

三、我们如何使用你的信息

  1. 提供和维护服务
    • 使用你的注册信息验证你的身份，确保你能正常登录和使用服务。
    • 根据你发送和接收的通讯信息，实现即时通讯功能，包括消息的发送、接收、存储和展示。
  2. 安全保障
    • 利用设备信息和位置信息进行安全监测和风险防控，防止账户被盗用、恶意攻击等安全事件。
  3. 自启动与关联启动
    • 场景：
      • 设备开机完成后，为确保你能及时接收消息通知，应用会自启动。
      • 网络连接状态发生变化时，为恢复消息同步，应用可能会关联启动。
      • 应用被意外关闭后，为持续提供消息通知服务，应用会尝试自启动。
    • 目的：保证消息通知的及时性和消息数据的同步，提升你的使用体验。
    • 规则：自启动或关联启动行为会在满足上述场景条件时自动触发。若你在应用设置中关闭相关功能，应用将不会自启动或关联启动。
    • 必要性：如果应用不进行自启动或关联启动，可能会导致消息接收延迟或消息数据不同步，影响你正常使用消息通知功能。

四、我们如何共享、转让和公开披露你的信息

  1. 共享
    • 我们不会将你的个人信息共享给任何第三方，除非满足以下条件：
      • 获得你的明确同意。
      • 为实现服务功能，与合作伙伴共享必要的信息，但我们会要求合作伙伴遵守严格的隐私保护约定。部分合作伙伴可能会使用以下第三方 SDK 来实现相应功能，这些 SDK 可能会收集和处理你的相关信息。
  2. 转让
    • 在涉及合并、收购、资产转让等交易时，如涉及个人信息转让，我们会要求新的持有方继续受本隐私协议的约束，否则我们将要求其重新征求你的同意。
  3. 公开披露
    • 我们仅会在法律要求、维护公共安全等必要情况下，公开披露你的个人信息。

六、你的权利

  1. 访问和修改
    • 你有权访问和修改你的账户信息、个人资料等信息，可通过应用内的设置功能进行操作。
  2. 删除
    • 在符合法律规定的情况下，你有权要求删除你的个人信息。
  3. 撤回同意
    • 你可以随时撤回之前给予我们收集和使用个人信息的同意，但这可能会影响你继续使用部分服务。同时，你也可以在应用设置中关闭自启动和关联启动功能，以及控制第三方 SDK 的使用。
  4. 账号注销
    • 你有权注销你的账户。如你需要注销账户，可以通过以下方式进行操作：在应用内点击「功能设置」-「账号与安全」-「注销账户」，按照页面提示完成身份验证后，即可提交注销申请。
    • 在你注销账户后，我们将根据相关法律法规的要求，删除或匿名化处理你的个人信息。但以下情况除外：
      • 法律法规另有规定的；
      • 为履行法定义务所必需的；
      • 为应对突发公共卫生事件，或者紧急情况下为保护自然人的生命健康和财产安全所必需的。
    • 请注意，账户注销是不可逆的操作，注销后你将无法再使用该账户登录本应用，也将无法恢复账户及相关数据，请谨慎操作。

七、信息存储和安全

  1. 存储地点
    • 我们会将你的个人信息存储在位于 [存储地点] 的服务器上。
  2. 安全措施
    • 我们采用加密技术、访问控制等安全措施，保护你的个人信息不被泄露、篡改和丢失。同时，我们要求第三方 SDK 开发者也采取相应的安全措施保障你的信息安全。
